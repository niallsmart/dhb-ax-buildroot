# Step 8: static and clean-build validation

Date: 2026-08-14

## Result

The reconciled maintained sources build successfully with pinned Linux
6.18.42 and Buildroot 2026.02.3. Both DTBs and both appended-DTB uImages were
regenerated. The final kernel patch queue applies without fuzz, offsets or
rejects, and the kernel/DT build emits no source compiler or DTC diagnostics.

Static inspection found and corrected three maintenance issues without
changing hardware behavior:

1. The checked-in full kernel configuration still contained compiler-derived
   values from Debian GCC 12.2. It now exactly matches the configuration
   regenerated by the pinned Buildroot GCC 14.3 toolchain.
2. The USB PHY node was named `usb-phy@200300b8` even though its first `reg`
   window begins at `0x20030000`. It is now `usb-phy@20030000`.
3. The registerless `i2c-gpio` controller was a child of the `simple-bus` SoC
   node. It is now a root child, which matches its lack of a `reg` property.

The two DTS changes remove the `simple_bus_reg` warnings produced when the
emitted Ethernet DTB was decompiled. The final DTBs decompile without warnings.

## Clean build and patch application

The Buildroot output volume `dhb-ax-br-output` was removed before the initial
build; the download cache was retained. The command was:

```text
scripts/buildroot.sh
```

The initial clean build completed with exit status zero. It exposed two line
offsets in patch 0003 (`+3` in the stmmac Kconfig and `+2` in its Makefile), but
no fuzz. The hunk headers were refreshed for the pinned source. The kernel
directory was then removed with `linux-dirclean` and the full image build was
run again. In the final log all ten patches apply without a `Hunk`, `offset`,
`fuzz`, reject or failure message.

The final kernel-stage log contains Buildroot make jobserver notices and, at
the time it was captured, a missing-hash warning for the local pinned kernel
tarball. That warning led to adding package hashes for both Buildroot consumers
of the archive (`linux` and `linux-headers`), using the SHA-256 published in
kernel.org's PGP-signed release manifest. A subsequent `linux-source` run
reports `linux-6.18.42.tar.xz: OK` and no missing-hash warning. No C compiler or
DTC warning is emitted while building the maintained kernel, modules, or device
trees. Warnings from unrelated Buildroot host
packages in the initial full-output build are not produced by this repository's
Linux patch queue.

Logs:

- `STEP-8-BUILD.log`: initial build from a completely empty output volume.
- `STEP-8-REBUILD.log`: final build after `linux-dirclean`, using the already
  built toolchain and packages.

## Emitted DTB inspection

The final decompiled trees are saved as
`STEP-8-hi3531-dhb-ax.decompiled.dts` and
`STEP-8-hi3531-dhb-ax-ethernet.decompiled.dts`.

Both DTBs contain:

- two 512 MiB memory ranges, `0x80000000..0x9fffffff` and
  `0xc0000000..0xdfffffff`;
- two Cortex-A9 CPUs and `enable-method = "hisilicon,hi3531-smp"`;
- GIC, SP804 and PL011 interrupts and the intended peripheral clock links; and
- no ATAG-derived memory metadata.

The Ethernet DTB additionally contains:

- exactly nineteen `arm,pl061`, `arm,primecell` GPIO banks, each with one
  peripheral clock and no parent interrupt;
- no `arm,primecell-periphid` override, consistent with the validated native
  IDs;
- root-level GPIO-I2C using GPIO12 offsets 4 and 5 with open-drain flags, and a
  `dallas,ds1307` child at address `0x68`;
- EHCI SPI 31 and OHCI SPI 32, both linked to the same Hi3531 USB PHY;
- SP805 clocks named `wdog_clk` and `apb_pclk`;
- Hi3531 AHCI at SPI 36;
- `hisilicon,hi3531-dwmac`, `snps,dwmac` at SPI 87 with the `stmmaceth`
  clock, plain RGMII, PHY address 1, and MAC `00:18:ae:3c:a2:49`; and
- no on-chip PL031 node.

## Schema and binding review

At this step, neither `dt-validate` nor `yamllint` was installed on the host or
in the Buildroot container. The emitted DTBs were therefore decompiled with
Linux's built `dtc`, and their properties were checked against the pinned
6.18.42 YAML bindings.

The standard binding requirements reviewed here are satisfied for PL061,
GPIO-I2C, DS1307, SP804, PL011, SP805, fixed clocks, generic EHCI/OHCI and the
generic DWMAC schema. Patch 0003 supplies a Hi3531 DWMAC schema; the emitted
node contains all properties it requires.

Step 10 closed this tooling and coverage gap. The reproducible build image now
contains pinned `dtschema` tooling and `yamllint`; YAML contracts cover the
local board/SoC, SMP method, system controller, UART mux, USB PHY, AHCI and
DWMAC compatibles. Strict schema validation and `dtbs_check` both pass. See
`STEP-10-FINALIZATION.md` for commands, versions and results.

## Guide disposition

This step found static source-maintenance issues, not a new factual conflict
with the early porting guide. No guide change was made.
